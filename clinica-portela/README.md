# Clínica Portela — site institucional

Abra index.html no navegador ou use Live Server no VS Code.

- WhatsApp e endereço do mapa: topo de js/main.js (CONFIG)
- Mensagem de cada botão: atributo data-msg no index.html
- Para usar uma foto no hero: troque a div .arches por uma <img> (otimizada, WebP)
